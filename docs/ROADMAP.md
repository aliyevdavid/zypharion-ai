# Zypharion Product Roadmap

This roadmap describes product direction, not delivery commitments. Items are
grouped by maturity, and every item outside **Implemented foundation** is
future work unless a repository change explicitly marks it complete.

## Implemented foundation

- FastAPI application factory, typed settings, health routes, and OpenAPI
  documentation
- Playwright inspection of a single public web page
- Stable browser-side snapshots for repeated page elements
- Structured browser observations and category-level extraction warnings
- Deterministic page classification, findings, recommendations, and confidence
- Structured evidence and explainable intelligence contracts
- Observable application behavior models
- Complete page-analysis service with controlled failure and partial-success
  states
- Provider-neutral AI engine and page-intelligence contracts
- Versioned, evidence-grounded prompt construction
- AI response normalization and schema validation
- Deterministic mock and Azure OpenAI provider adapters
- Automated unit and API coverage for current components

## Near-term (future)

- Deepen behavior discovery across navigation, forms, authentication, search,
  and data-entry flows
- Convert behavior contracts into traceable test-design proposals
- Identify coverage gaps and prioritize scenarios by quality risk
- Define browser and API execution contracts with structured artifacts
- Improve failure taxonomy, retries, timeouts, and diagnostic evidence
- Establish pull-request CI as a required quality gate before adopting a
  main-based branch workflow
- Add security controls for target validation, network boundaries, secrets,
  and retained artifacts

## Mid-term (future)

- Introduce persistent organizations, projects, applications, and analysis runs
- Add tenant isolation, authentication, authorization, and audit trails
- Map multi-page applications within explicit crawl and session boundaries
- Integrate existing test suites and CI/CD systems
- Select relevant validation using changes, behaviors, risk, and history
- Diagnose and cluster failures using deterministic evidence plus optional AI
- Present coverage, execution health, and release-quality views in a web UI
- Evaluate AI prompts and providers against curated quality-engineering datasets

## Later (future)

- Optimize suites by identifying redundancy, instability, cost, and signal
- Add retrieval-grounded organizational quality memory with citations and data
  isolation
- Correlate requirements, code changes, behavior, tests, defects, and releases
- Support guarded recommendations for test maintenance and pull requests
- Provide release-risk forecasting with transparent evidence and uncertainty
- Explore Quality Autopilot for continuous, permissioned quality coordination
  with auditability and human approval for consequential actions

## Product boundary

Future roadmap entries are not available product claims. Zypharion currently
provides backend page extraction, deterministic intelligence, application
behavior contracts, and optional AI enhancement. Broader SaaS workflows,
autonomous actions, and release decisions require additional product,
security, evaluation, and operational work.
